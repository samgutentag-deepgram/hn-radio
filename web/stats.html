What is stored

Each event is one line in a file on the server: a timestamp, an episode id, and which of the six things happened. No IP address, no user agent, no cookie, no visitor id, nothing that persists past the browser tab. “One play per listener” is worked out in your own browser with sessionStorage, which is why the server never needs to know who you are to avoid counting you twice. Close the tab and that memory is gone; open the episode tomorrow and you count again.
